# BakeryProduction — AnyLogic 8.9.1

Имитационная модель производственно-логистической системы хлебозавода: **17 процессов**, четыре внешних Source, движение работников, материальные партии, склад, снабжение, мельница, выпечка, упаковка, отгрузка.

## Актуальная версия

**v23 — читаемая схема и последовательное поступление заказов**.

- У 17 процессов выровнены рамки, входные и выходные порты.
- Сохранены 48 смысловых подписей потоков IDEF0/DFD, подписи — чёрные.
- Сохранены 165 объектов и 161 соединение Main.
- Первый заказ поступает через 3 модельные минуты, последующие — после завершения предыдущего и приёмки его излишков с паузой 6 минут.
- Сценарии: 1 водитель (**BOTTLENECK**) и 4 водителя (**IMPROVED**). Гипотеза об узком месте ещё требует запуска модели.

**Важно:** статические проверки XML проведены. Компиляция и выполнение в AnyLogic 8.9.1 ещё не подтверждены.

## Комплект выпуска v23

Исходный полный архив `Bakery_v23_FINAL_COMPLETE.zip` содержит модели:

- `Bakery_v23_MAIN.alp`
- `Bakery_v23_BOTTLENECK.alp`
- `Bakery_v23_IMPROVED.alp`
- `Bakery_v22_BACKUP.alp`

а также PNG-ресурсы, проверочные скрипты и предпросмотры.

**Статус загрузки через GitHub API:** документы и инструменты подготовки размещаются в репозитории отдельно; перечисленные выше бинарные/крупные файлы будут считаться опубликованными только после отдельной проверки их наличия в GitHub. Для добавления полного архива с локального компьютера предусмотрен `tools/import_v23.py`.

## Структура после импорта

- `model/` — три варианта v23 и резервная v22.
- `assets/` — PNG, необходимые модели.
- `docs/` — предпросмотры и исходные заметки.
- `tools/` — скрипты проверки и сборки.

## Импорт полной версии

Скачайте `Bakery_v23_FINAL_COMPLETE.zip` из чата ChatGPT, затем из корня локальной копии этого репозитория запустите:

```bash
python tools/import_v23.py /путь/к/Bakery_v23_FINAL_COMPLETE.zip
git add .
git commit -m "model: add complete BakeryProduction v23"
git push
```

После импорта откройте `model/Bakery_v23_MAIN.alp` в AnyLogic 8.9.1. Рядом с моделью должны быть доступны PNG-ресурсы (при необходимости укажите путь к ним в проекте).
