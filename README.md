# BakeryProduction — AnyLogic 8.9.1

Имитационная модель производственно-логистической системы хлебозавода: 17 процессов, четыре внешних `Source`, материальные партии, склад, мельница, выпечка, упаковка и отгрузка.

## Текущая версия: v23

- Переработана читаемость блоков и портов, исправлены отдельные маршруты соединений.
- 48 смысловых подписей потоков IDEF0/DFD отображаются чёрным цветом.
- Сохранены 165 объектов и 161 соединение `Main`.
- Заказы поступают последовательно: первый через 3 модельные минуты, следующий через 6 минут после окончания предыдущего и приёмки излишков.
- Экспериментальные версии: `BOTTLENECK` (1 водитель) и `IMPROVED` (4 водителя).

**Статус проверки:** структура XML проверялась статически; компиляция и выполнение в AnyLogic 8.9.1 остаются неподтверждёнными. Гипотеза об узком месте ещё требует экспериментального прогона.

## Загрузка полной модели через сайт GitHub

Большие ALP/PNG не передаются напрямую из окружения ChatGPT в GitHub API. Репозиторий уже содержит автоматический импорт. Чтобы загрузить весь исходный комплект **одним действием**:

1. Скачайте `Bakery_v23_FINAL_COMPLETE.zip` из беседы ChatGPT.
2. Перейдите в каталог [incoming](incoming) этого репозитория.
3. Нажмите **Add file → Upload files** и загрузите ZIP **без переименования**.
4. Откройте вкладку **Actions → Import BakeryProduction v23 release** и дождитесь завершения проверки и коммита.

Workflow распаковывает и проверяет архив, а затем размещает **все 41 файл** в `releases/v23/`. PNG остаются рядом с моделями, как в исходном архиве.

В архиве четыре файла модели:

- `Bakery_v23_MAIN.alp`
- `Bakery_v23_BOTTLENECK.alp`
- `Bakery_v23_IMPROVED.alp`
- `Bakery_v22_BACKUP.alp`

Также присутствуют 33 PNG, скрипты `verify_v23.py` и `build_v23.py`, технический отчёт и предпросмотры.

Если workflow завершится с ошибкой записи, в **Settings → Actions → General → Workflow permissions** включите **Read and write permissions** и повторите выполнение.

## Альтернативный локальный импорт

```bash
python tools/import_v23.py /путь/к/Bakery_v23_FINAL_COMPLETE.zip
git add releases/v23
git commit -m "model: import complete BakeryProduction v23"
git push
```

## Структура

- `incoming/` — папка для ZIP-релиза.
- `.github/workflows/import-release.yml` — автоматический импорт и XML-проверка.
- `tools/import_v23.py` — переносимый распаковщик с манифестом SHA-256.
- `releases/v23/` — все ALP, изображения и отчёты из исходного архива **после импорта**.

Чтобы открыть модель, используйте `releases/v23/Bakery_v23_MAIN.alp`. Скрипт `build_v23.py` — исторический скрипт сборки, содержащий пути исходной рабочей среды; для обычного открытия модели он не требуется.
